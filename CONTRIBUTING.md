# Contributing to openflow

Thanks for helping with **openflow**, an AI-powered macOS dictation client.

This repository is the Mac client only. The backend lives elsewhere.

## Getting started

Building from source requires:

- macOS 26 or later on Apple Silicon
- Xcode
- `openflow.xcodeproj`

Open the project in Xcode, choose your signing team, and build the `openflow` scheme.

## How to contribute

1. Search [existing issues](https://github.com/Willebrew/openflow/issues) before opening a new one.
2. Fork the repository and create a branch from `main`.
3. Make a focused change.
4. Open a pull request against [`Willebrew/openflow`](https://github.com/Willebrew/openflow) `main`.

## What makes a good pull request

- One concern per PR -- keep the diff focused and reviewable.
- Match the existing Swift style and project structure.
- Do not commit secrets, API keys, certificates, or local credentials.
- Describe what changed and why.

## Issues

Search open and closed issues first. If you file a new one, include the macOS version, how you built or installed openflow, and steps to reproduce.
